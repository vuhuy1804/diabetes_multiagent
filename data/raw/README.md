# Public training dataset (not bundled)

Download **Diabetes Prediction Dataset** from:
https://www.kaggle.com/datasets/iammustafatz/diabetes-prediction-dataset

Extract the CSV and place it at exactly:
`data/raw/diabetes_prediction_dataset.csv`

Required columns: `gender`, `age`, `hypertension`, `heart_disease`,
`smoking_history`, `bmi`, `HbA1c_level`, `blood_glucose_level`, `diabetes`.
Do not change column names. The project ignores extra CSV columns.

Do not put identifiable, real personal health data in this directory.
Check the dataset's license and provenance before redistributing it.
